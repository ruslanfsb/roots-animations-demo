# Демо анимаций для Roots Flowers

Копия главной страницы [roots-store.ru](https://roots-store.ru) со спокойными анимациями.
Вверху есть переключатель «С анимациями / Как сейчас»: адрес с `?off` показывает страницу без анимаций.

## Что в папке

| Файл | Зачем |
|---|---|
| `roots-animations.css`, `roots-animations.js` | **Сами анимации.** Только эти два файла нужны для настоящего сайта. |
| `index.html` | Снимок главной страницы. Стили, шрифты и фото грузятся с серверов Roots. Счётчики, чаты и скрипты сайта убраны. |
| `demo/` | Обвязка только для демо: плашка сверху, простой слайдер и вкладки вместо скриптов сайта. На сайт не переносится. |
| `screenshots/` | Скриншоты на 1440 и 390 px. Сеть при проверке была закрыта, поэтому вместо фото на них серые заглушки. |
| `letter.md` | Письмо владельцу. |

## Анимации

Раскадровка с таймингами — в Figma: <https://www.figma.com/design/7GHI0pxu4TAdFO93H0s7Zz>.

**Фон и общий ритм**
- Живой фон: три мягких цветовых пятна в палитре букетов медленно дрейфуют под секциями (цикл 48–62 с).
- Тонкая линия прогресса прокрутки цвета `#BE8D71` у верхнего края.

**Первый экран**
- Заголовок слайда раскрывается по словам из-под маски, затем проявляется кнопка «Смотреть».
- Фото слайда медленно «садится» на место (эффект Кена Бёрнса) и при прокрутке уходит медленнее страницы.
- Полоска активного слайда заполняется за время показа (нужен атрибут `data-ra-autoplay="мс"` на `.main_slider`, равный задержке автопрокрутки).

**Тексты**
- Заголовки разделов («Акции», «Соберем заказ по вашим пожеланиям», «Блог», «Все возможности в приложении»…) раскрываются по словам, когда доходят до экрана.
- Курсивные слова получают тонкую акцентную линию.

**Блоки**
- Сторис появляются по очереди, кольцо непросмотренных медленно вращается.
- Плитки категорий открываются «шторкой» снизу вверх; при наведении приподнимаются, заголовок и стрелка сдвигаются.
- Карточки, карусели, преимущества и контакты появляются «лесенкой» при прокрутке.
- Коллаж «Соберем заказ» и телефон с приложением движутся с разной скоростью — глубина; телефон медленно «парит».

**Карточка букета**
- Наклон за курсором (до 3°) с мягким бликом, фото увеличивается, состав поднимается снизу, название — `#BE8D71`, «+» у цены поворачивается.
- «В корзину» / «Быстрый заказ»: подъём при наведении, «вдавливание» при нажатии; корзина в шапке подпрыгивает.
- Сердечко вспыхивает кольцом, бейдж скидки изредка мягко пульсирует, при смене вкладки товары появляются по очереди.

Движение — `transform`, `translate`, `scale`, `opacity` (шторка плиток — `clip-path`), `IntersectionObserver`, один обработчик прокрутки через `requestAnimationFrame`, без библиотек.
Учтена настройка «уменьшить движение» (`prefers-reduced-motion`): тогда всё статично.
Если JS не загрузился, ничего не остаётся скрытым. То, что видно на первом экране при загрузке, не мигает и не прыгает.

## Как подключить на настоящем сайте

1. Положить `roots-animations.css` и `roots-animations.js` в корень сайта (или в `/themes/v3/`).
2. В `<head>`, **после** основного `style.css`:
   ```html
   <link rel="stylesheet" href="/roots-animations.css">
   ```
3. Перед `</body>`, после скриптов сайта:
   ```html
   <script src="/roots-animations.js" defer></script>
   ```

Больше ничего менять не нужно: файлы опираются на текущие классы сайта (`.item`, `.main_category`, `.story`, `.badge.sale`, `.favorite`, `.button_buy`, `.cart_top`, `#popular_toggler`, `.main_slider .owl-item.active`, `#personal_imgs`, `.about_app`).\nДля заполняющейся полоски слайдера добавьте к `.main_slider` атрибут `data-ra-autoplay` с задержкой автопрокрутки owl.carousel в миллисекундах.
Чтобы временно выключить анимации без удаления файлов, добавьте `<html data-ra-off>`.

## Как открыть демо по ссылке

**GitHub Pages (бесплатно):**
1. Settings → General → Danger Zone → Change visibility → **Public**. На бесплатном тарифе Pages работает только для публичных репозиториев.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты демо откроется по адресу `https://ruslanfsb.github.io/roots-animations-demo/`.

**Netlify Drop (без настройки):** Code → Download ZIP, распаковать и перетащить папку на <https://app.netlify.com/drop>.
Чтобы ссылка не пропала через час, войдите в бесплатный аккаунт Netlify.

Страница помечена `noindex`, поисковики её индексировать не будут.
